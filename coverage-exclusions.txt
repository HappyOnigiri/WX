# 正確な repository-relative path<TAB>理由
cmd/wx/main.go	Process entrypoint and stdio dispatch adapter; command behavior is exercised by binary and RPC integration tests.
cmd/wx/daemon.go	Daemon lifecycle, launchd, process, and Unix-socket adapter; behavior is exercised by process and RPC integration tests.
cmd/wx/config.go	Configuration command stdio and daemon reload RPC adapter; behavior is exercised by CLI integration tests.
cmd/wx/resume.go	Resume command stdio and agent client adapter; behavior is exercised by CLI integration tests.
cmd/wx/status.go	Status/Doctor stdio, RPC, and local diagnostics adapter; behavior is exercised by CLI and RPC integration tests.
cmd/wx/slots.go	Slots command stdio and RPC adapter; behavior is exercised by CLI and RPC integration tests.
cmd/wx/maintenance.go	Maintenance command stdio and RPC adapters; behavior is exercised by CLI and RPC integration tests.
cmd/wx/rpc.go	CLI RPC client construction adapter; behavior is exercised by RPC integration tests.
internal/cli/client.go	Agent process, signal, and terminal adapter; lifecycle behavior is exercised by real child-process integration tests.
internal/daemon/server.go	Daemon process, filesystem, lock, and Unix-socket adapter; behavior is exercised by real-process integration tests.
internal/launchd/launchd.go	macOS launchd adapter; plist and launchctl behavior is exercised by integration tests that put a stub launchctl on PATH, which needs no macOS host.
internal/workspace/cow_clone.go	clonefile adapter reached only after a successful clone; linux always fails cloneCOW with ENOTSUP, so the replacement path is exercised by the darwin CoW tests.
internal/cli/doctor_probe.go	Daemon RPC round-trip and progress-output adapter for wx doctor --probe; the findings it builds are exercised by doctor_probe_report_test.go and the checks by doctor_probe_worktree_test.go.
